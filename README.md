# MiniMap

Union plugin for **Gothic I** and **Gothic II: Night of the Raven** that adds a corner minimap and an interactive full-screen world map generated directly from world geometry.

Works in every world and mod without requiring an in-game map item.

## Features

- **Corner Minimap** — Square or circular view, 12 sizes, 4 frame styles, fixed north or camera-rotating mode.
- **Interactive Full Map** — Cursor zoom, drag panning, custom player markers with notes, and a minimap guide arrow.
- **Generated Terrain & Detail Tiles** — Height shading, ground colors from world textures, paths, buildings, interiors, caves, and fog of war, cached automatically on disk.
- **Map Icons & Tooltips** — NPCs, traders, lootable corpses, items by category, chests by lock type, interactive objects, switches, teleports, and level transitions with hover tooltips.
- **Search & Item Table** — Live search by name or category (including inside chests, corpses, and trader goods) and a world item summary table.
- **In-Game Menu & Mod Configs** — Configurable live under `Options -> Union & Plugins -> MiniMap` (English, Polish, German, Czech) or via text files in `MiniMap\config\` and `MiniMap\mods\<mod>\`.

## Installation

1. Make sure **Union 1.0m+** is installed.
2. Download **`MiniMap.vdf`** from [**Releases**](../../releases).
3. Copy `MiniMap.vdf` to `Data\Plugins\` (or `Data\`).
